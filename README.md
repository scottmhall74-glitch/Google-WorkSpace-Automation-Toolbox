# Google-WorkSpace-Automation-Toolbox
This is a series of scripts that I have in Google Scripts that either do Mail Merge like tasks with Google Docs and Emailing. I have used tools like this for the WMEC Rendezvous which had over 2,000 participants to help with communication for presenters and attendees.

Example scripts I have are:
  New Hire Form - This is a Google Form that a supervisor uses when they hire a new employee to let HR, Central Office and IT know that there is a new hire. It takes a template document and puts in the appropriate        information into the correct fields. 

Log In Letter Generator
  This creates a menu in a Google Screadsheet where information and inventory is put in for a new staff member. Once it is complete the user can use the custom menu it creates and then input in the row(s) they want to run the mail merge on and it will take the template and replace the appropriate information where needed. This can then be shared or printed and given to the new staff member. This also has approprate URLs within the template and IT Help Desk Proceedures to help them get started. 

Certificate Generator
  In education staff get certificates of hours when they do any professional development that is needed for their recertification. Where we offer almost a dozen inhouse trainings per year this form records who was in attendance and the session, date and amount of hours and then when the user is ready they use the custom menu to run all of the data in the current tab to create certificates for the staff, email the certificates to them, and also put that certificate in a Shared Drive folder that is named their email address and they have rights to view in. This way if they lose the email they can look in that folder to find all their inhouse certificates.
